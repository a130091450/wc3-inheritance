# 属性系统设计（v1.0 定稿）

> 魔兽3 自定义地图《无尽刷怪》· 属性系统
> 架构：**引擎原生常数为主 + 单个生命补丁**（v0.x 的"完全自管"方案已废弃）

## 一、设计目标

1. 按自定义系数换算属性（力量×2 生命、敏捷×1 生命、智力×0.5 生命等）
2. 尽量交给魔兽原生机制，减少触发器覆盖带来的跳变/冲突
3. 装备等"直接加数值"的来源可叠加，互不覆盖

## 二、架构总览

**核心结论：除「敏捷/智力加生命」外，其余全部由游戏常数完成。**

| 属性关系 | 由谁负责 | 实现 |
|---|---|---|
| 力量 → 生命 | **引擎** | 常数 `StrHitPointBonus` = 2 |
| 力量 → 生命回复 | **引擎** | 常数 `StrRegenBonus` = 0.01 |
| 智力 → 魔法 | **引擎** | 常数 `IntManaBonus` = 1 |
| 智力 → 魔法回复 | **引擎** | 常数 `IntRegenBonus` = 0.01 |
| 敏捷 → 护甲 | **引擎（关闭）** | 常数 `AgiDefenseBonus` = 0 |
| 敏捷 → 攻速 | **引擎（关闭）** | 常数 `AgiAttackSpeedBonus` = 0 |
| 主属性 → 攻击 | **引擎** | 原生 1:1（力量型受 `StrAttackBonus` 控制） |
| **敏捷×1 + 智力×0.5 → 生命** | **触发器** | 唯一需要补的项 |
| 装备直接加 血/蓝/回血/回蓝/攻 | 触发器（阶段 2） | 装备系统落地时再处理 |

> **白字攻击说明**：白字攻击 = 基础攻击（物编）+ 主属性×1，引擎自动算。
> 敏捷/智力型主属性同样 1:1，但**倍率不可配置**（没有 AgiAttackBonus / IntAttackBonus 常数）。
> 全局可配的只有 `StrAttackBonus`（仅对力量型英雄有效）。

## 三、换算系数（定稿）

| 来源 | 目标 | 系数 | 实现 |
|---|---|---|---|
| 力量 | 生命 | ×2 | 引擎常数 |
| 敏捷 | 生命 | ×1 | **触发器补** |
| 智力 | 生命 | ×0.5 | **触发器补** |
| 智力 | 魔法 | ×1 | 引擎常数 |
| 力量 | 回血/秒 | ×0.01 | 引擎常数 |
| 智力 | 回蓝/秒 | ×0.01 | 引擎常数 |
| 主属性 | 攻击 | ×1 | 引擎原生 |
| 敏捷 | 护甲 | 0 | 引擎常数（关闭） |
| 敏捷 | 攻速 | 0 | 引擎常数（关闭） |

## 四、游戏常数改动清单（6 项）

通过改地图 `misc.ini`（解包 → 改 → `w2l obj` 打包），或编辑器「游戏平衡性常数」界面。

| 常数 | 默认 | 改成 | 原因 |
|---|---|---|---|
| `StrHitPointBonus` | 25 | **2** | 力量每点 +2 生命 |
| `StrRegenBonus` | 0.05 | **0.01** | 力量每点 +0.01 回血 |
| `IntManaBonus` | 15 | **1** | 智力每点 +1 魔法 |
| `IntRegenBonus` | 0.05 | **0.01** | 智力每点 +0.01 回蓝 |
| `AgiDefenseBonus` | 0.30 | **0** | 敏捷不加护甲 |
| `AgiAttackSpeedBonus` | 0.02 | **0** | 敏捷不加攻速 |

> `StrAttackBonus` 保持 1.0（主属性→攻击 1:1）。

## 五、单位模板改动

| 单位 | 改动 | 原因 |
|---|---|---|
| `H000`（英雄） | **最大生命设为 0**、最大魔法设为 0 | 让血量/蓝量 100% 由属性决定，不含模板基数 |

> 若不改模板，引擎算出的血量会多出模板自带的 100 点，与"纯属性驱动"的设计冲突。

## 六、唯一的触发器：生命补丁

### 6.1 目标公式

```
英雄最大生命 = 力量×2（引擎算） + [敏捷×1 + 智力×0.5]（触发器补）
```

触发器只负责方括号里的部分。

### 6.2 方案 A：SetUnitState 覆盖（简单，有抖动）

```
每秒对每个英雄：
    dqdyHP = 力量*2 + 敏捷*1 + 智力*0.5
    SetUnitState(英雄, MAX_LIFE, dqdyHP)
    if 当前生命 > dqdyHP then SetUnitState(LIFE, dqdyHP)   // 钳制
```

| 优点 | 缺点 |
|---|---|
| 精确（支持 0.5）、无需建技能、实现最快 | 升级瞬间引擎重算为"力量×2"（少了敏捷/智力部分），**1 秒内血量偏低**，跳变幅度 ≈ 敏捷+智力/2（约 15~50） |

### 6.3 方案 B：生命加成技能（无抖动，推荐）

用"生命加成"类技能（物品生命加成系）作为载体，用 `SetUnitAbilityLevel` 控制等级：

```
技能等级 = 敏捷 + 智力/2（向下取整）
每级 +1 生命
```

- 引擎自己维护这个加成，**升级不会丢、无跳变**
- 精度：整数（智力 0.5 用"每 2 点智力 +1 生命"表达）

| 优点 | 缺点 |
|---|---|
| 无抖动、升级稳定 | 需建技能；等级上限受限（敏捷+智力/2 超过 200 时需多技能组合） |

### 6.4 建议

- **先做方案 A**（最快跑通，验证数值）
- 若玩家反馈跳变明显 → 换方案 B

## 七、未来扩展：装备直接加成（阶段 2）

装备分两类，走不同入口：

| 装备类型 | 例子 | 处理 |
|---|---|---|
| **加属性** | "巨人腰带 +10 力量" | 直接改属性（`SetHeroStr`），引擎自动换算血量/攻击 |
| **加数值** | "生命宝石 +300 生命" | 走 `Stat_Mod`（触发器记账） |

### 7.1 `Stat_Mod`（阶段 2 才建）

```
入参：ModTarget(unit) / ModField(int) / ModDelta(real)
字段：1=生命 2=回血 3=蓝量 4=回蓝 5=攻击
逻辑：累加到对应 Base 变量 → 重算生命补丁时一并加入
```

**前提**：装备记账必须带唯一标识，防重复拾取重复加（详见第九节）。

## 八、属性提示文案（war3mapSkin.txt）

### 8.1 原理

地图根目录放 `war3mapSkin.txt`，用 `[FrameDef]` 段覆盖界面文本，`|n` 换行可让一条文本显示成多行。

### 8.2 可用的 8 个位置

| 键 | 原版含义 | 所在属性栏 |
|---|---|---|
| `BONUS_HITPOINTS` | 力量 → 生命 | 力量 |
| `BONUS_HPREGEN` | 力量 → 生命回复 | 力量 |
| `BONUS_MANA` | 智力 → 魔法 | 智力 |
| `BONUS_MANAREGEN` | 智力 → 魔法回复 | 智力 |
| `BONUS_DEFENSE` | 敏捷 → 护甲 | 敏捷 |
| `BONUS_DEFENSE_FIXED` | 敏捷 → 固定护甲 | 敏捷 |
| `BONUS_ATTACK_SPEED` | 敏捷 → 攻速 | 敏捷 |
| `BONUS_DAMAGE` | 敏捷 → 伤害 | 敏捷 |

### 8.3 本图最终文本

```ini
[FrameDef]
; 力量栏
BONUS_HITPOINTS=-每点力量增加2点生命
BONUS_HPREGEN=-每点力量增加0.01点/秒生命回复

; 敏捷栏（不加护甲/攻速 → 改成加生命；空值不展示）
BONUS_DEFENSE=-每点敏捷增加1点生命
BONUS_DEFENSE_FIXED=
BONUS_ATTACK_SPEED=

; 智力栏
BONUS_MANA=-每点智力增加1点魔法
BONUS_MANAREGEN=-每点智力增加0.01点/秒魔法回复 |n-每点智力增加0.5点生命

; 攻击（原版挂在敏捷栏，改写为主属性说明）
BONUS_DAMAGE=-每点主属性增加1点攻击力（力量/敏捷/智力中最高的一项）
```

### 8.4 实施注意

| 项 | 要求 |
|---|---|
| 文件位置 | 地图**根目录** `war3mapSkin.txt`（不是 `war3imported\`） |
| 编码 | 1.27 中文版用 **ANSI/GBK** |
| 覆盖优先级 | 编辑器若勾了"自定义游戏界面常数"会覆盖此文件 → 需取消 |
| `%d` | 只有 `BONUS_HITPOINTS`/`BONUS_MANA`/`BONUS_DEFENSE` 支持；回血/回蓝两条必须写死数字 |
| 空值 | `BONUS_ATTACK_SPEED=` 留空是否完全隐藏**需实测** |

## 九、幂等 / 性能 / 并发防护

### 9.1 生命补丁的前置检查

```jass
if 英雄 == null then return endif                    // 玩家离开后 HeroP[pid] 为 null
if IsUnitAliveBJ(英雄) == false then return endif    // 死亡时不刷
```

### 9.2 重入防护

- 补丁里不注册/不触发任何会回调自身的事件
- 若将来监听"获得 buff"等事件，加 `Refreshing[pid]` 标志位防递归

### 9.3 装备记账防重复（阶段 2）

- 装备数据必须带唯一标识（物品句柄 / 装备 ID）
- 记账前检查"是否已记账"（哈希表 `装备句柄 → 已记账`）

### 9.4 小数血量

`智力×0.5` 会产生小数（如 25 智力 → 12.5）。写入前取整：

```jass
dqdyHP = R2I(力量*2 + 敏捷*1 + 智力*0.5 + 0.5)   // 四舍五入
```

### 9.5 性能

4 英雄 × 1 次/秒 = 4 次/秒，可忽略。即使扩到 8 英雄也无压力。

## 十、调用场景清单

### 10.1 需要触发生命补丁的场景

| # | 场景 | 现状 |
|---|---|---|
| 1 | 英雄创建完成 | ✅ 已有（`V3_Init`） |
| 2 | 英雄升级（引擎加属性） | ✅ 引擎行为，挂 `EVENT_PLAYER_HERO_LEVEL` 监听 |
| 3 | 破境加属性（`V3_TierUp`） | ✅ 已有（需补调用） |
| 4 | 英雄复活 | ✅ 已有（`V3_Death` 的 ReviveHero 后） |
| 5 | 1 秒周期兜底 | ➡️ 待建 |
| 6 | 装备加属性/数值（未来） | ⬜ 阶段 2 |

### 10.2 判断口诀

> **"这个改动会不会让某个英雄的敏捷或智力发生变化？"**
> 会 → 需要重算生命补丁
> 不会 → 不用管（其他属性引擎自己处理）

### 10.3 分阶段实施

**阶段 1（现在做）**

1. 改 6 个游戏常数（第四节）
2. 改 `H000` 模板：最大生命 / 最大魔法 = 0
3. 建 `Stat_Patch` 触发器：每秒设最大生命 = 力量×2 + 敏捷×1 + 智力×0.5（含判空、钳制）
4. 挂 `EVENT_PLAYER_HERO_LEVEL` 监听（升级后立即补一次）
5. `V3_TierUp`（破境）加属性后补一次
6. `V3_Death`（复活）后补一次
7. 建 `war3mapSkin.txt`（第八节）
8. 起图验证：初始血量 = 10×2 + 10×1 + 10×0.5 = **35**、升级不跳变、破境血量立涨

**阶段 2（做装备时）**

1. 建 `Stat_Mod`（装备直接加血/蓝/回血/回蓝/攻）
2. 装备拾取/丢弃/替换监听 + 防重复记账

**阶段 3（做加点/道具时）**

1. 加点界面
2. 属性之书（只加属性即可，引擎自动换算）

## 十一、已定结论汇总

| # | 项 | 决定 |
|---|---|---|
| 1 | 架构 | 引擎原生常数为主 + 单个生命补丁 |
| 2 | 力量 → 生命 | 常数 `StrHitPointBonus=2` |
| 3 | 力量 → 回血 | 常数 `StrRegenBonus=0.01` |
| 4 | 智力 → 魔法 | 常数 `IntManaBonus=1` |
| 5 | 智力 → 回蓝 | 常数 `IntRegenBonus=0.01` |
| 6 | 敏捷 → 护甲/攻速 | 常数设 0（关闭） |
| 7 | 主属性 → 攻击 | 引擎原生 1:1，**不做倍率变化** |
| 8 | 敏捷×1 + 智力×0.5 → 生命 | **触发器补**（阶段 1 唯一自建逻辑） |
| 9 | 初始基础血量 | 模板 hp 设 0，血量 100% 由属性决定 |
| 10 | 掉上限 | 直接钳制 |
| 11 | 升级重写 | 引擎重算的就是正确值（因为只用常数），补丁部分靠升级事件 + 每秒兜底维持 |
| 12 | 攻击力 buff | **不使用**（攻击走原生主属性机制） |
| 13 | 装备直接加数值 | 阶段 2 用 `Stat_Mod` |
| 14 | 属性提示文案 | `war3mapSkin.txt` + `|n` 换行塞多条 |

## 十二、调研结论（存档）

| 主题 | 结论 |
|---|---|
| `SetUnitState(MAX_LIFE)` | 覆写语义，会覆盖物品/技能加成，且英雄升级会重写 → 只用于补丁 |
| 主属性 → 攻击 | 引擎原生 1:1 白字；`StrAttackBonus` 仅对力量型可配 |
| 敏捷/智力 → 攻击 | 不存在对应常数，倍率锁死 1 |
| 敏捷/智力 → 生命 | 不存在对应常数，必须触发器补 |
| 力量/智力 → 回血回蓝 | 常数 `StrRegenBonus` / `IntRegenBonus` 存在 |
| hook override | 拦不到引擎内部重算函数（非 native），不采用 |
| 白字 vs 绿字 | 白字只能来自基础攻击（物编）+ 主属性；buff/技能都是绿字 |
