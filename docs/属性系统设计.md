# 属性系统设计（v1.2）

> 《无尽刷怪》· 血量自管，其余属性交给引擎原生常数

## 一、架构分工

| 属性 | 谁负责 |
|---|---|
| **最大生命** | **触发器自管**：`基础血量 + 属性血量` |
| 生命回复 / 魔法 / 魔法回复 / 护甲 / 攻速 | 引擎（游戏常数） |
| 攻击力 | 引擎原生（主属性 ×1，白字） |

## 二、血量公式

```
最大生命 = BaseHP（基础血量）+ (力量×2 + 敏捷×1 + 智力×0.5)
```

- `BaseHP` 初始 **0**，装备/技能/书 直接加的数值累加到此
- 初始属性 10/10/10 → 血量 = 0 + 20 + 10 + 5 = **35**

## 三、游戏常数（6 项）

改地图 `misc.ini`（解包→改→`w2l obj` 打包）。

| 常数 | 默认 | 改成 |
|---|---|---|
| **`StrHitPointBonus`** | 25 | **0**（血量自管，引擎不参与） |
| `StrRegenBonus` | 0.05 | 0.01 |
| `IntManaBonus` | 15 | 1 |
| `IntRegenBonus` | 0.05 | 0.01 |
| `AgiDefenseBonus` | 0.30 | 0 |
| `AgiAttackSpeedBonus` | 0.02 | 0 |

> `StrAttackBonus` 保持 1.0。

## 四、变量

```jass
integer BaseHP[4]    基础血量（初始 0）
real    AttrHP[4]    属性血量（缓存，便于调试/UI）
unit    ModTarget    传参：目标
real    ModDelta     传参：血量增量
```

## 五、触发器

### 5.1 `Stat_Refresh` — 唯一写血量的地方

**入参**：`RfTarget`（unit）
**调用时机**：属性变化、升级、复活、1 秒周期、`Stat_Mod` 之后

```
if RfTarget == null then return                  // 玩家离开
if IsUnitAliveBJ(RfTarget) == false then return  // 死亡不刷

pid = GetPlayerId(GetOwningPlayer(RfTarget))
AttrHP[pid] = 力量*2 + 敏捷*1 + 智力*0.5
if BaseHP[pid] < 0 then BaseHP[pid] = 0          // 负数保护

newMax = R2I(BaseHP[pid] + AttrHP[pid] + 0.5)    // 四舍五入
SetUnitState(RfTarget, MAX_LIFE, newMax)
if 当前生命 > newMax then SetUnitState(RfTarget, LIFE, newMax)  // 直接钳制
```

### 5.2 `Stat_Mod` — 改基础血量（装备/书 唯一入口）

**入参**：`ModTarget`、`ModDelta`

```
pid = GetPlayerId(GetOwningPlayer(ModTarget))
BaseHP[pid] = BaseHP[pid] + ModDelta
Stat_Refresh(ModTarget)
```

| 场景 | ModDelta |
|---|---|
| 捡「生命宝石 +300」 | +300 |
| 丢掉它 | -300 |

## 六、单位模板

`H000`：最大生命 = **0**、最大魔法 = 0、力量/敏捷/智力 = **10/10/10**（写进物编，创建即 35 血，无跳变）。

## 七、调用场景

| # | 场景 | 调用 |
|---|---|---|
| 1 | 英雄创建（`V3_Init`） | `Stat_Refresh` |
| 2 | 英雄升级（`EVENT_PLAYER_HERO_LEVEL`） | `Stat_Refresh` |
| 3 | 破境加属性（`V3_TierUp`） | `Stat_Refresh` |
| 4 | 英雄复活（`V3_Death`） | `Stat_Refresh` |
| 5 | 1 秒周期兜底 | `Stat_Refresh` |
| 6 | 装备/书 直接加血（未来） | `Stat_Mod` |
| 7 | 装备加属性（未来） | `Stat_Refresh` |

**判断口诀**：力量/敏捷/智力 或 BaseHP 变了 → 要刷；其他不用管。

## 八、防护要点

| 项 | 处理 |
|---|---|
| 判空 / 存活 | `Stat_Refresh` 开头两行 return |
| BaseHP 负数 | 钳到 0 |
| 小数血量 | `R2I(x + 0.5)` |
| 重入 | Refresh 内不注册/触发回调自身的事件 |
| 引擎重算 | `StrHitPointBonus=0` + 模板血 0 → 引擎算出 0，靠属性变化点同步刷新 + 1 秒兜底补回 |
| 装备重复记账 | 装备带唯一标识 + 哈希表防重（阶段 2） |

## 九、属性提示文案（war3mapSkin.txt）

地图根目录 `war3mapSkin.txt`，`[FrameDef]` 段，`|n` 换行：

```ini
[FrameDef]
BONUS_HITPOINTS=-每点力量增加2点生命
BONUS_HPREGEN=-每点力量增加0.01点/秒生命回复
BONUS_DEFENSE=-每点敏捷增加1点生命
BONUS_DEFENSE_FIXED=
BONUS_ATTACK_SPEED=
BONUS_MANA=-每点智力增加1点魔法
BONUS_MANAREGEN=-每点智力增加0.01点/秒魔法回复 |n-每点智力增加0.5点生命
BONUS_DAMAGE=-每点主属性增加1点攻击力（力量/敏捷/智力中最高的一项）
```

| 注意 | 要求 |
|---|---|
| 位置 | 地图**根目录**（不是 `war3imported\`） |
| 编码 | 1.27 中文版用 **ANSI/GBK** |
| 覆盖 | 编辑器勾了"自定义游戏界面常数"会覆盖此文件 |
| `%d` | 只有 HITPOINTS/MANA/DEFENSE 支持；回血/回蓝写死数字 |

## 十一、调研结论（备查）

| 主题 | 结论 |
|---|---|
| `SetUnitState(MAX_LIFE)` | 覆写语义；英雄升级会重写 → 需同步 + 周期刷新 |
| 主属性 → 攻击 | 引擎原生 1:1 白字；`StrAttackBonus` 仅对力量型可配 |
| 敏捷/智力 → 攻击 | 无对应常数，倍率锁死 |
| 敏捷/智力 → 生命 | 无对应常数，必须触发器算（本方案核心） |
| 力量/智力 → 回血回蓝 | 常数 `StrRegenBonus` / `IntRegenBonus` 存在 |
| hook override | 拦不到引擎内部函数，不采用 |
| 白字 vs 绿字 | 白字只能来自基础攻击（物编）+ 主属性 |
